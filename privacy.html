Privacy policy

This policy covers the profile-only development component described on this site. It does not describe the original Ruby Launcher or its separate login system. The operator must review this policy before public application release.

Scope

This policy covers this informational website and the proposed Ruby Personal Secure OAuth test component. It does not cover the original Ruby Launcher, Roblox, or third-party websites.

Information processed

The component requests the openid and profile scopes. Its source obtains the Roblox user ID, username and display name from Roblox's userinfo endpoint and displays them locally. An authorization code, PKCE verifier, state and OAuth access token are processed temporarily to complete the request. The code does not request Roblox passwords, session cookies, payment details or private messages.

Use and retention

Identity information is used only to demonstrate authorization and profile retrieval. The current component does not write tokens or profiles to a database or file and does not implement persistent login. Console output may remain visible or be saved by the operating system, terminal or user. Roblox retains its own authorization records under its policies.

Sharing and hosting

The component sends authentication requests to Roblox's official endpoints. This static website has no analytics scripts, sign-in form, advertising or application database. GitHub Pages hosts the website and may process standard request logs such as IP addresses and browser information under GitHub's privacy statement.

Your choices

You may decline authorization, close the test program, clear local console output and revoke app access through Roblox's account settings. Revoking access does not necessarily erase records retained by Roblox or a hosting provider. Do not share tokens or authorization codes in support requests.

Children and eligibility

Use is limited to users eligible to authorize Roblox OAuth apps under Roblox's rules. The component does not collect date of birth and is not intended for users below Roblox's applicable OAuth age requirement.

Security

The source uses PKCE, random state, a loopback callback and HTTPS for requests to Roblox. These are design measures, not a guarantee of security; the implementation is not yet independently tested.

Contact and changes

Contact the project operator via the project issue tracker for general support. Issues are public; never post credentials, tokens or personal information there. The operator must revise this policy if the component or hosting arrangements change.
