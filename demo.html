Authorization demo guide

There is no verified recording yet. A real recording is required to demonstrate what reviewers will actually use.

Prepare

  1. Install the Rust toolchain and any required Windows build tools.
  2. Use the configured component supplied by the operator. Close the original Ruby Launcher.
  3. Confirm the registered app name, scopes and redirect address match the source.
  4. Run a successful authorization test before recording.

Recording sequence

Start signed out of the application. Show the exact action that launches authorization, Roblox's consent screen, the redirect, and the application's actual returned profile information. Hide secrets and callback query parameters, not the consent screen. Keep the recording under one minute.

Do not submit a staged recording, simulated login, or the original Ruby login as proof of the new integration. If submitting the original Ruby integration, demonstrate that integration after it works.
