Ruby Personal Secure is an experimental desktop authentication component intended to support a future authorized integration with Ruby Launcher. It uses Roblox's OAuth authorization flow for basic profile information.

Development status: The Rust source is prepared, but compilation, live authorization and integration into the original Ruby Launcher have not been verified. This website is not a sign-in portal and does not collect Roblox credentials. Do not use it to sign into the original launcher.

Official authorization

The component opens the default browser and directs authorization to Roblox.

Limited permissions

Only openid and profile are requested for identity information.

Local testing

OAuth tokens are used transiently by the test code; persistent token storage is not implemented.

Developer test

Access is restricted to authorized development testers. The configured source is supplied separately by the application operator; there is no public executable release. Review the privacy terms before testing.
